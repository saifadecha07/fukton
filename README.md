# ฝึกตน

แอป Android สำหรับฝึกสติ ฝึกใจ และฝึกความตั้งใจในการเรียน ได้แรงบันดาลใจจากขัคควิสาณสูตร
("จงเป็นดั่งราชสีห์ ที่ไม่ตื่นเสียง จงเป็นดั่งสายลม ที่ตาข่ายมิอาจจับได้…") และแนวเจริญสติแบบเคลื่อนไหวของหลวงพ่อเทียน จิตฺตสุโภ

## ดาวน์โหลด

ไปที่หน้า **Releases** ของ repository นี้ แล้วดาวน์โหลดไฟล์ `fukton-vN.apk` ตัวล่าสุด
ติดตั้งทับตัวเดิมได้ ข้อมูลที่ฝึกไว้ยังอยู่ (ข้อมูลทั้งหมดเก็บในโทรศัพท์เท่านั้น ไม่ส่งขึ้นอินเทอร์เน็ต)

## สิ่งที่มีในแอป

- **วันนี้** — สระบัวที่บานตามการฝึก, ตั้งใจประจำวัน, ห้าสิ่งที่ตั้งใจ, ใจสะอาด (งดสื่อด้านลบ), ไพ่ธรรมประจำวัน
- **ฝึก** — เรียนในห้อง, ดูลมหายใจ, จังหวะมือ 14 ท่า, เรียนอย่างมีสติ
- **ลาน** — เกมฝึกใจ (นับลมหายใจ, บัวชมพู บัวทอง, อ่านใจ, จำทางดอกบัว, รู้กาย) และฝึกคิด (ไขปริศนา, คิดเร็ว, การ์ดทวนจำ), เมล็ดบัว แต่งสระ อัลบั้มไพ่ธรรม
- **คาถา** — ถ้อยคำไทยพร้อมความหมายและสิ่งที่ลองทำได้วันนี้
- **เส้นทาง** — สถิติ สระบัวสะสม เหรียญ

## Build

- บน GitHub: ทุกครั้งที่ push ขึ้น `main` จะ build APK และสร้าง Release ให้อัตโนมัติ (`.github/workflows/build-apk.yml`)
  ต้องตั้ง secret `DEBUG_KEYSTORE_B64` เป็นกุญแจเซ็นแอปแบบ base64 เพื่อให้ติดตั้งทับเวอร์ชันเดิมได้
- บนเครื่อง Windows: `powershell -ExecutionPolicy Bypass -File build-apk.ps1`
